# Designing well in Cosmic

Use for a new design or a substantial redesign. For a small requested edit, preserve the established direction and inspect the affected area.

The first decision is what this product helps someone do. Choose a composition around that activity. A media library might prioritize recognizable footage, selection and review; an editorial publication might prioritize reading rhythm. Do not begin from the same sidebar, oversized headline and three equal cards for every brief.

Before drawing, choose an art direction with a reason: audience, mood, information density, a type pairing, neutral surfaces and a purposeful accent. Compare a few plausible directions internally and commit to one. References should change concrete decisions about proportions, imagery, typography or interaction. Do not copy branding. No palette, fashionable effect, font family or card pattern is mandatory across projects.

Build a coherent system of margins, columns, repeated spacing, type sizes, border treatment and interactive states. Use the canvas's editable borders, restrained shadows, gradients, line-height and letter-spacing where they support that direction. Keep a clear dominant area and intentional secondary areas. Useful density is preferable to empty decorative panels in a working application. Familiar controls should remain recognizable.

Use plausible domain-specific content: filenames, dates, durations, labels, project names and actual workflows. Avoid generic marketing copy in a working tool and do not put implementation disclaimers, design scores, token lists or capability explanations on the canvas. Put material prototype limitations in the accompanying summary. Never imply an external operation actually happened.

Use native vector icons for ordinary actions. Choose raster imagery when subject matter, photographic texture or distinctive illustration adds value; do not generate it merely because the tool exists. Prefer a few purposeful assets to an entire rasterized interface. Import each finished asset promptly, place it, and keep text and controls editable.

Finish the interactions that carry the design: navigation, selected states, local search/filtering when relevant, connected values and visible feedback. Give controls enough space and consistent hover/focus treatment. A nonfunctional label over a rectangle is unfinished.

Render at a useful scale. Inspect hierarchy, text fit, contrast, repeated alignment, cropping and awkward empty space. For a new design, make one focused refinement pass against the actual rendered result before presenting it. Fix the most consequential weakness rather than adding decoration. Test the principal interaction and a reset/back path. Preserve stable IDs and unrelated user edits when iterating. Report what was actually inspected; don't substitute an invented quality score for evidence.
